Act as a product manager defining success metrics for a new feature.

Feature: [FEATURE_NAME]
Intended outcome: [INTENDED_OUTCOME]

Produce:
1. One primary success metric, defined precisely (what counts, what doesn't).
2. Two to three supporting metrics that give context to the primary one.
3. A guardrail metric to watch to make sure the feature isn't causing harm elsewhere.
4. The threshold or target that would count as success.
