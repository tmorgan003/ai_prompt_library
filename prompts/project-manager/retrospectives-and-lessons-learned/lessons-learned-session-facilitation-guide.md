Project: [PROJECT_NAME]
Project summary: [PROJECT_SUMMARY]

Produce:
1. Four opening questions to get honest input (what went well, what didn't, what surprised us, what would we do differently).
2. A method to prioritize which lessons are worth turning into process changes.
3. A template for capturing each lesson as: Observation, Root Cause, Recommendation, Owner.
